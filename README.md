# Physics PhD Atlas

面向物理学 PhD 申请者的静态导师线索网页。当前版本按 **2027 QS 世界大学排名**筛出美国院校中的前 30 所，并为每所学校整理 1 位具有官方机构页面的代表性教授或研究员。

## 页面功能

- 按姓名、学校和研究关键词搜索
- 按研究方向、研究方式与排名口径筛选
- 展示学校 QS 全球排名、教授职位、研究关键词及官方主页
- 响应式布局，可直接部署到 GitHub Pages

## 数据口径

- 学校范围：[QS World University Rankings 2027](https://www.topuniversities.com/qs-top-uni-wur)
- 导师资料：大学、院系或实验室官方页面
- 最后核验：2026-09-27

这是一份申请调研起点，不是完整院系名录。页面中的导师不一定正在接收博士生；申请前应再次核对导师主页、近期论文、实验室成员、经费与院系招生要求。

## 本地预览

无需安装依赖。用任意静态文件服务器打开 `dist` 目录即可，例如：

```powershell
python -m http.server 4173 --directory dist
```

然后访问 `http://127.0.0.1:4173`。

## 发布

仓库包含 GitHub Pages 工作流。推送到 `main` 分支后，会将 `dist` 目录发布为静态网站。
